Privacy Policy

Apps Script Cache is a personal tool run by its owner. It is not a public service.

What it does with Google Drive

With the owner's permission (Google scope drive.file), the app creates one folder named “Apps Script Cache” in the owner's Google Drive and saves the latest JSON response of each configured Google Apps Script web app there. It can only see and change files it created itself — never any other file in the Drive.

What data is stored

  • The JSON responses of the owner's own Apps Script URLs (in Google Drive and/or Cloudflare D1).
  • Settings for each source (name, URL, refresh interval) and fetch logs, which are deleted automatically after 7 days.

No data is sold, shared with third parties, or used for advertising.

Removing access

The owner can revoke Google access at any time at myaccount.google.com/permissions and delete the “Apps Script Cache” folder.
